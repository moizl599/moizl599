## 🛡️ About

I work at the intersection of **security operations** and **cloud infrastructure**. Most of what I build connects SIEM and security tooling to the wider ecosystem — getting Wazuh, Acunetix, and the platforms around them to talk to each other so detection and response actually flows end to end. Lately I've also been building **local-first FinOps for Kubernetes**.

- 🔭 Currently building **[Steward](https://github.com/moizl599/Steward)** — local-first FinOps for Kubernetes
- 🔐 Focused on **SIEM integrations, vulnerability management, and security automation**

- 💬 Ask me about **Wazuh, security integrations, and DevSecOps**
